## Welcome to FLEX Partner API

The FLEX Partner API enables partners to manage terminals, process transactions, and implement payment splitting functionality. Build powerful point-of-sale solutions integrated with the FLEX ecosystem.

## Key Features

### 🏪 Terminal Operations
Dedicated terminal endpoints for point-of-sale operations with complete transaction tracking.

### 💸 Split Payments
Advanced payment splitting functionality to distribute payments across multiple recipients.

### 📱 QR Code Integration
Generate dynamic QR codes for both regular terminal payments and split payment scenarios.

### 🔐 Secure Authentication
All API requests authenticated using partner credentials with support for terminal-specific operations.

## Authentication

All Partner API endpoints require authentication using your partner credentials:

- **x-client-id**: Your partner client ID
- **x-api-key**: Your partner API key

<Note>
  Some terminal endpoints also require a valid terminal identifier in the request headers.
</Note>

## Quick Start

<Steps>
  <Step title="Get API Credentials">
    Contact FLEX support to receive your partner credentials:
    - Client ID (`x-client-id`)
    - API Key (`x-api-key`)
    - Terminal serial numbers (if applicable)
  </Step>

  <Step title="Set Up Terminals">
    Configure your terminals and obtain their serial numbers for authentication
  </Step>

  <Step title="Test Integration">
    Start with terminal profile retrieval and transaction initiation
  </Step>

  <Step title="Go Live">
    Deploy to production after testing in staging environment
  </Step>
</Steps>
